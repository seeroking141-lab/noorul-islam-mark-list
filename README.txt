Noorul Islam Madrasa Mark List

Files:
- index.html: webpage structure
- style.css: design and styling
- script.js: JavaScript functionality

To use:
1. Keep all three files in the same folder.
2. Open index.html in a browser to test.
3. For GitHub, upload all three files to the same repository root.
4. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

Note: This project uses JavaScript (.js), not Java (.java).
